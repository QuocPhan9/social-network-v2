# social-network-v2

A modern and responsive social media web application built with **ReactJS**.

## 🛠️ Tech Stack

- **Frontend:** ReactJS, React Router, Axios, Redux Toolkit, Socket.IO
- **UI:** Tailwind CSS, React Icons
- **Backend:** Node.js + Express + MongoDB

---

## 📦 Installation



### 1. Clone the repository

```bash
git clone https://github.com/QuocPhan9/social-network-v2.git
cd social-network-v2
git checkout develop
```

### 2. Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### 3. Start the development server and client

```bash
cd client
npm run dev
```

```bash
cd server
npm run dev
```
